# 15 谜题与置换的奇偶性

一个可以在浏览器里玩的小演示：4×4 滑块拼图，起点是"只把 14 和 15 互换"的局面。

## 玩法

- 点空格旁边的数字就能滑动。
- 「两块互换的局面」：经典的无解起点，怎么滑都回不到目标。
- 「换个能解的局面」：随机打乱一个真能解开的局面，可以试试把它复原。
- 「揭晓为什么」：给出"只交换两块"永远解不开的完整理由。

右下角的**不变量**是「逆序数 ＋ 空格从下往上数的行号」模 2，它对每一步滑动都不变：
目标局面是 1，"两块互换"是 0。所以那个数字怎么滑都不会变。

## 为什么解不开

1. 目标是把 1–15 排好、空格在右下角；一次滑动，就是空格和相邻的那个数字交换位置。
2. 每滑一次，都可以看成给整个排列乘上一个对换，所以每滑一步，排列的奇偶性就翻转一次。
3. 但要回到目标局面，空格必须回到出发的那一格：它在格子里走的是一条回路。
   把格子像棋盘一样染色，空格每走一步都换颜色，所以回路只能是偶数步。
4. 偶数步滑动＝偶数个对换＝偶置换。也就是说，从目标局面出发能到达的每个局面，
   都对应 15 个数字的一个偶置换。
5. 而"只把 14 与 15 互换"是 1 个对换，是奇置换。奇偶性对不上，所以永远滑不回去。

按群论的说法：偶置换全体 A₁₅ 是 S₁₅ 中指数为 2 的子群，可达局面只落在它的一个陪集里，
"只差一次对换"的局面正好落在另一个陪集。
